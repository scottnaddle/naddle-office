# 영상 브리프 작성 지침

이 지침은 AI가 만든 HTML 애니메이션 장면을 앱이 프레임 단위로 녹화해 영상으로 만드는 작업에 적용됩니다. 장면 하나가 영상 한 편이며, 결과물은 소리가 없는 짧은 영상입니다.

## 1. 페이지 계약

- 페이지는 처음에 멈춘 상태로 시작합니다. 스스로 재생을 시작하지 않습니다.
- 다음 객체를 반드시 정의합니다.

  ```
  window.naddleVideo = {
    durationMs: 25000,
    seek(ms) { /* draw the frame at ms */ },
  }
  ```

- `durationMs`는 브리프가 정한 길이와 같아야 하고 90000을 넘지 않습니다.
- `seek(ms)`는 0 이상 `durationMs` 이하의 시각을 받아 그 시점의 화면을 그립니다. 같은 시각을 몇 번 호출해도 같은 화면이어야 합니다.
- 앱은 시간을 스스로 흘리지 않고 이 함수로만 장면을 앞뒤로 옮깁니다. `requestAnimationFrame`에 기대어 스스로 흐르는 애니메이션은 쓰지 않습니다.

## 2. 쓸 수 있는 라이브러리

- 앱이 제공하는 라이브러리만 씁니다. 브라우저 기본 애니메이션(WAAPI, CSS), anime.js, three.js입니다.
- 라이브러리는 앱 안의 `naddle-video-lib://` 주소에서만 불러옵니다.
- GSAP은 쓸 수 없습니다. CDN, 외부 스크립트, 외부 글꼴도 쓸 수 없습니다.
- 글꼴은 시스템 글꼴이나 앱이 넣어 둔 글꼴만 씁니다. 글꼴 파일을 네트워크에서 받지 않습니다.
- three.js는 3D 템플릿에서만 씁니다. 그 밖의 템플릿은 WAAPI/CSS와 anime.js로 만듭니다.

## 3. 금지 사항

- 네트워크를 쓰지 않습니다. `fetch`, `XMLHttpRequest`, `WebSocket`, `navigator.sendBeacon`, 원격 `import()`를 쓰지 않습니다.
- `<video>`, `<audio>`, `<iframe>`, `<object>`, `<embed>`를 넣지 않습니다. 배경음, 내레이션, 효과음도 넣지 않습니다. 이 앱의 영상은 무음입니다.
- 무작위 값은 고정 시드 없이 쓰지 않습니다. 같은 장면을 두 번 녹화했을 때 같은 결과가 나와야 합니다.
- `eval`, `new Function`, 동적으로 만든 코드 문자열을 쓰지 않습니다.
- 카메라, 마이크, 클립보드, 알림, 위치 권한을 요청하지 않습니다.
- 새 창을 열거나 다른 주소로 이동하지 않습니다.

## 4. 화면과 글자

- 안전 여백을 둡니다. 가장자리에서 가로·세로 각각 화면 너비의 5% 안쪽은 비워 둡니다.
- 본문 글자는 1080p 기준 24px보다 작게 하지 않습니다. 제목은 그보다 크게 합니다.
- 글자와 배경의 대비를 충분히 둡니다. 색만으로 정보를 구분하지 않습니다.
- 화면 비율은 브리프가 고른 16:9, 9:16, 1:1 가운데 하나로 고정하고, 그 밖의 비율을 섞지 않습니다.

## 5. 길이와 성능

- 길이는 최대 90초입니다. 브리프의 `durationSec.default`를 기준으로 하고 `min`~`max`를 벗어나지 않습니다.
- 해상도는 1920×1080, 1080×1920, 1080×1080 가운데 비율에 맞는 하나를 씁니다. 이보다 크게 만들지 않습니다.
- 프레임률은 30fps를 넘지 않습니다.
- 한 프레임을 5초 안에 그려야 합니다. 무거운 그림자, 필터, 수십 개의 동시 애니메이션을 피합니다.
- 생성하는 HTML은 1MB를 넘지 않습니다.

## 6. 내용

- 쓰는 사람이 주지 않은 숫자, 회사 이름, 사람 이름, 제품 이름을 지어내지 않습니다.
- 숫자는 입력한 표기를 그대로 씁니다. 반올림하거나 단위를 바꾸지 않습니다.
- 확인하지 않은 사실을 단정하는 문장을 넣지 않습니다.
- 브리프 질문에 없는 내용은 넣지 않습니다. 빈칸은 비워 두고 지어내지 않습니다.

## 7. 3D 쇼케이스

- three.js 장면은 기본 도형(상자, 원기둥, 구, 원뿔, 평면 등)만으로 만듭니다.
- 외부 glTF, OBJ, FBX 같은 모델 파일을 읽지 않습니다.
- 재질은 기본 재질과 색으로 표현하고, 외부 텍스처 이미지를 쓰지 않습니다.
- WebGL을 쓸 수 없는 환경에서는 3D 템플릿을 렌더할 수 없다는 것을 전제로 합니다.
