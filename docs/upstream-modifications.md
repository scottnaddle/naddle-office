# 업스트림 파일 수정 기록 (원장)

> 이 저장소의 규칙: **업스트림 파일은 이 목록에 올린 것만 수정한다.** 목록에 없는 업스트림 파일을 고치는 PR은 게이트에서 막힌다.
> 이 문서는 P0-3(훅·원장 구조)이 원장으로 넘겨받기 전까지의 기록지입니다. 원장이 만들어지면 아래 항목을 원장 형식으로 옮기고, 이 문서는 "옮겨간 기록"으로 남깁니다.
> 근거 표기: `[직접확인]` = 직접 확인한 것 · `[추정]` = 판단 · `[보고]` = 다른 에이전트 보고 인용.

---

## 기록 형식

| 항목              | 설명                                                            |
| ----------------- | --------------------------------------------------------------- |
| **파일**          | 수정 대상 경로(저장소 루트 기준)                                |
| **줄**            | 수정한 위치(현재 줄 번호)                                       |
| **수정**          | 무엇을 바꿨는지(변경 전 → 변경 후)                              |
| **이유**          | 왜 필요한가 — 근거(파일:줄·실행 결과) 포함                      |
| **되돌리는 방법** | 이 수정을 되돌리려면 무엇을 해야 하는가                         |
| **업스트림 PR**   | 업스트림(`pblsketch/openoffice`)에 같은 수정을 제안할 수 있는가 |

## 1. `tools/check-no-genspark.mjs` — 출처 표기 허용 항목 4개 추가

**상태**: 머지됨 (PR #10, `ba0da41`) + PR #17 (열림)

| 항목              | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **파일**          | `tools/check-no-genspark.mjs`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| **줄**            | `:91` · `:97` · `:103` · `:109`·`:110` (ALLOW 배열)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| **수정**          | ALLOW 항목 4개 — `path: '.github/README.md'` / `path: 'NOTICE-NADDLE.md'` / `path: 'docs/plan.md'` / `path: 'docs/upstream-modifications.md'`. 앞 3개는 각 `span: /github\.com\/genspark-ai\/genoffice/g`(출처 URL), 4번째는 **같은 URL을 정규식 리터럴로 이스케이프한 형태**입니다 — 본 문서가 그 span을 그대로 인용하기 때문이라, 이스케이프하지 않으면 게이트가 본 문서를 잡습니다                                                                                                                                                                                                                                                                                                                                                                                                                    |
| **이유**          | 게이트가 **나들오피스 저장소 자체의 Apache-2.0 §4 출처 표기 4건**을 잡아, `main`의 `test` job이 step 16에서 멈췄습니다. `[직접확인]` `origin/main`을 체크아웃해 `node tools/check-no-genspark.mjs` 실행 → 동일한 4건으로 exit 1 (`.github/README.md:16`·`:42`, `NOTICE-NADDLE.md:3`, `docs/plan.md:568`). | **되돌리는 방법** | ALLOW의 네 항목만 삭제하면 됩니다. 앞 3개를 삭제하면 게이트가 다시 4건을 잡고, 4번째를 삭제하면 게이트가 이 문서를 잡아 `test` job이 step 16에서 멈춥니다. 되돌리기 전에 표기 대상(4개 파일의 해당 URL)을 함께 정리해야 게이트가 통과합니다                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| **업스트림 PR**   | **불필요** — 업스트림 저장소에는 이 4개 파일이 없습니다(나들오피스 전용 파일). 업스트림 `ALLOW` 구조는 그대로 두었습니다                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

## 4. `.github/workflows/ci.yml` — job 타임아웃 상향 (test 45→90분, e2e 60→120분)

**상태**: PR #15 (열림)

| 항목              | 내용                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **파일**          | `.github/workflows/ci.yml`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |

| **이유**          | `[직접확인]` run `42751508873`의 attempt 1·2가 **모두** `ci.yml:26`의 45분 job 한도에서 취소됐습니다(annotation `The job has exceeded the maximum execution time of 45m0s`). attempt 1은 45m19s에 step 23 `Test`(단위 테스트) 진행 중, attempt 2는 45m15s에 step 21 진행 중에서 종료됐습니다. 워크플로 결함이 아니라 **예산 부족**입니다 — 이 저장소 러너는 업스트림 러너보다 1.1~1.7배 느립니다(업스트림 대비 스펙별 소요 23.1s vs 8.2s 등). 그 결과 **단위 테스트 스위트가 한 번도 끝까지 실행된 적이 없습니다**. e2e도 한도 60분 중 47m17s·44m20s(한도의 79%)까지 소요돼 여유가 없었습니다. 단위 테스트 미검증 상태를 없애려면 두 job의 한도를 함께 올려야 합니다 |
| **되돌리는 방법** | `:30`의 `90`을 `45`로, `:182`의 `120`을 `60`으로 되돌리고 추가한 영어 주석 6줄(`:26`–`:29`·`:180`–`:181`)을 지우면 업스트림 원문과 다시 바이트 동일해집니다. 되돌리면 단위 테스트가 다시 45분 한도에 걸립니다                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
